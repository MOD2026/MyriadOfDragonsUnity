# MVP First Session Script v1

**READY FOR CC — Yes / No:** Approve this as Zihan's first human-session script after CC declares the MVP spine green?

**When:** Not now. Run only after `MVP_PLAYABLE_GATE_v1` is green.  
**Limit:** 10–12 minutes. Use a fresh profile. Do not use developer tools, retries outside the normal player route, or value changes.

## 1. Tutorial — about 3 minutes

- [ ] Start from Home and begin Tutorial.
- [ ] Follow only the instructions the game gives you.
- [ ] Finish the Tutorial and return to Home.

**Stop and note:** If you do not know the next action, cannot complete an instructed action, or cannot return safely to Home, stop. Record the screen and the exact words that confused you.

## 2. Deck confirm — about 2 minutes

- [ ] Open Deck Builder from Home.
- [ ] Build or accept a legal deck through the normal interface.
- [ ] Confirm/Save it, then return using the normal route.

**Stop and note:** If it is unclear why the deck is illegal, whether it saved, or where it will be used, stop. Record the visible deck count/status.

## 3. Campaign 1-1 — about 4 minutes

- [ ] Open Campaign and select 1-1.
- [ ] Read the launch requirements, then launch normally.
- [ ] Form a squad, start combat, and finish or leave through the normal result path.
- [ ] Return to Home if the game offers that action.

**Stop and note:** If launch appears to do nothing, a required resource/deck state is unexplained, a battle action is unclear, or you reach a screen with no safe next action, stop. Capture one screenshot.

## 4. Optional: Shop one pack — about 2 minutes

- [ ] Only if you have the required currency naturally, buy one ordinary pack.
- [ ] Verify the result appears in Collection.

**Stop and note:** If cost, result, or ownership outcome is unclear, stop. Do not buy around the issue or force duplicate/burn testing.

## 5. Collection glance — about 1 minute

- [ ] Open Collection and identify the newly obtained card or one starter card.
- [ ] Look at the available progression actions without trying to exhaust every branch.

**Stop and note:** If the screen suggests a free shortcut, hides a requirement, or gives no explanation of an unavailable action, stop and note the wording.

## Explicit skip list

- UI polish, final art, animation flair, layout tuning, and screenshot comparisons.
- Bazaar/trading and every Phase-2 market feature.
- Weekly Permit rotation, trusted server week keys, server claims, and Permit migration.
- Forge/Dust yield changes or Evolution Gold-curve discussion.
