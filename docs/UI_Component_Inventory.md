## Scope

This inventory catalogs the reusable UI components that already exist in the current Unity project. The project builds its UI procedurally at runtime rather than through a formal component library, so the components below are inferred from the actual presenter scripts and runtime UI construction paths.

## Summary

The current project already contains a meaningful set of UI building blocks, but they are implemented as one-off runtime objects rather than a shared library. The strongest opportunities for a reusable component library are:

1. Buttons and button variants
2. Header and navigation shell components
3. Panels and modal/overlay wrappers
4. Card tiles and card detail surfaces
5. Scroll/list containers and list items
6. Tooltips and narrative popups

The biggest technical gap is not the absence of UI elements; it is the absence of a shared construction and styling contract for those elements.
